The 16S rRNA gene amplicon sequencing analysis was done with [DADA2](https://benjjneb.github.io/dada2/) and [Phyloseq](https://joey711.github.io/phyloseq/). For more detailed information about each software, please refer to their pages and publications.

The script used for DADA2 is named: [dada2-mcrA.R](https://github.com/mlbonatelli/Schroeder_et_al._2026/blob/main/mcrA_amplicon/dada2-mcrA.R). And for the raw data, please consult the BioProject PRJNA1300313 at NCBI.

For phyloseq, all information can be easily visualized in [mcrA_phyloseq_git.md](https://github.com/mlbonatelli/Schroeder_et_al._2026/blob/main/mcrA_amplicon/mcrA_phyloseq_git.md). To see all the code for the phyloseq analysis, please consult the file [16S_analysis_git_just_code.Rmd](https://github.com/mlbonatelli/Schroeder_et_al._2026/blob/main/mcrA_amplicon/mcrA_phyloseq_git_just_code.Rmd).

For the figures of the published paper, please go to [figures_article](https://github.com/mlbonatelli/Schroeder_et_al._2026/tree/main/mcrA_amplicon/figures_article).
